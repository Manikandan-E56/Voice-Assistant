An ultra-low latency, empathetic voice assistant built to speak and converse like a genuine real-life friend (**"machi / bro"**). Features local Speech-to-Text, local LLM generation via Ollama, zero-shot voice cloning with Coqui XTTS-v2, and a dual-tier persistent memory bank (SQLite + ChromaDB).

Optimized specifically for code-switching and **Tanglish** (Tamil written in Latin script), English, and Hindi, with tailored architectural design to run smoothly on consumer laptop GPUs (e.g., NVIDIA RTX 3050 with 4GB VRAM).

## ✨ Key Highlights

- **Natural Spoken Dialogue**: Prompt engineered to speak in 1–3 concise, warm, emotionally attuned sentences. Strictly strips markdown formatting, emojis, and stage directions.
- **Bilingual & Tanglish Native**: Equipped with custom phonetic Tanglish hints for Whisper and tailored system instructions for natural South Indian colloquialisms (`"machi"`, `"vidu da"`, `"pathukalam"`, `"sapdiya"`, `"tension aagadha"`).
- **Pipelined Asynchronous Speech (Zero Waiting)**: Streams tokens into sentence buffers. The audio pipeline begins synthesizing and playing sentence $N$ while sentence $N+1$ is still being generated by the LLM.
- **Zero-Shot Voice Cloning**: Clones any voice from a short reference WAV file using Coqui XTTS-v2.
- **Dual-Layer Long-Term Memory**:
  - **Relational Profile (SQLite)**: Stores static user facts (name, job, key preferences).
  - **Semantic / Vector Memory (ChromaDB)**: Embeds and retrieves past emotional events and conversation highlights filtered by vector distance threshold.
- **Local & Private**: Runs entirely locally on your machine with Ollama and Faster-Whisper.

## 🏛️ Architecture & The Four Pillars

```
                     ┌────────────────────────┐
                     │   User Microphone 🎙️   │
                     └───────────┬────────────┘
                                 │
                                 ▼
                     ┌────────────────────────┐
                     │     1. THE EAR         │
                     │  Faster-Whisper (CPU)  │
                     │  (Tanglish VAD & Hint) │
                     └───────────┬────────────┘
                                 │ Transcribed Text
                                 ▼
┌──────────────────┐ ┌────────────────────────┐ ┌──────────────────┐
│ SQLite (Facts)   ├─►│     2. THE BRAIN       │◄┤ ChromaDB (Vector)│
│  - User Name     │ │  Ollama (Qwen2.5 /     │ │  - Emotional logs│
│  - Occupation    │ │          Llama3.2)     │ │  - Past memories │
└──────────────────┘ └───────────┬────────────┘ └──────────────────┘
                                 │ Sentence-by-sentence Stream
                                 ▼
                     ┌────────────────────────┐
                     │     3. THE MOUTH       │
                     │  Coqui XTTS-v2 (GPU)   │
                     │  + Asynchronous Player │
                     └───────────┬────────────┘
                                 │
                                 ▼
                     ┌────────────────────────┐
                     │     Speaker / Audio 🔊 │
                     └────────────────────────┘
```

### 1. 👂 The Ear (`ear.py`)
- **Engine**: Local `faster-whisper` (`base` model, `int8` quantization).
- **Phonetic Prompting**: Injects a custom Tanglish vocabulary hint (`config.TANGLISH_HINT`) into Whisper’s initial prompt, dramatically increasing accuracy for Tamil-English hybrid phrasing.
- **Fallback**: Automatically falls back to Google Speech Recognition (`speech_recognition`) if offline models encounter an issue.
- **VAD Filter**: Uses Voice Activity Detection to prune silence and background noise.

### 2. 🧠 The Brain (`brain.py`)
- **Engine**: Ollama serving `qwen2.5:3b` (primary for multilingual/Tanglish reasoning) with `llama3.2` as fallback.
- **Streaming Pipeline**: Parses token output through a sentence-boundary regex delimiter (`.`, `!`, `?`, `\n`) to yield speakable chunks in real time.
- **Sliding Context Window**: Automatically prunes conversation turns (`MAX_HISTORY_TURNS = 10`) to prevent unbounded VRAM growth.
- **Context Injection**: Ephemerally injects retrieved SQLite facts and ChromaDB memories as system directives without polluting chat history.

### 3. 🗣️ The Mouth (`mouth.py`)
- **Engine**: Coqui XTTS-v2 zero-shot neural voice cloning.
- **Pipelined Playback Worker**: A dedicated background thread with a thread-safe `queue.Queue` consumes generated audio chunks and plays them through `sounddevice` sequentially while subsequent sentences are synthesized in parallel.
- **Audio Normalization**: Cleans punctuation, pauses, and symbols to eliminate TTS stuttering.

### 4. 💾 The Memory (`memory.py`)
- **Structured Knowledge (SQLite)**: Stores key-value facts inside `memory/facts.db`. Automatically extracts names and occupations from conversation.
- **Semantic Episodic Memory (ChromaDB)**: Persists emotional events, moods, and conversation milestones inside `memory/chroma_store`. Uses cosine distance thresholding (`RELEVANCE_DISTANCE_THRESHOLD = 1.2`) to only retrieve context that is strictly relevant.

## ⚡ Hardware & Performance Tuning

Specially tuned for laptop setups with limited VRAM (e.g., **ASUS ROG Zephyrus / Strix G15 with RTX 3050 4GB GPU**):

| Component | Target Device | Quantization / Settings | Rationale |
|---|---|---|---|
| **Faster-Whisper (Ear)** | **CPU** | `int8` | Takes 0 MB GPU VRAM; completes in ~150ms on modern multi-core CPUs. |
| **Ollama LLM (Brain)** | **GPU / CPU** | `qwen2.5:3b` (`num_ctx: 2048`) | Low memory footprint (~2GB VRAM), leaves sufficient space for XTTS. |
| **XTTS-v2 (Mouth)** | **CUDA** | `cuDNN disabled` | Prevents Windows cuBLAS/cuDNN status mismatch crashes while maintaining realtime synthesis. |
| **Memory (ChromaDB)** | **CPU / Disk** | Persistent local store | Zero GPU overhead. |

## 🚀 Installation & Setup

### 1. Clone the Repository
```bash
git clone https://github.com/Manikandan-E56/Assistant-Voice.git
cd Assistant-Voice
```

### 2. Create and Activate Conda Environment
```bash
conda create -n assistant-voice python=3.10 -y
conda activate assistant-voice
```

### 3. Install PyTorch with CUDA 12.1
```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

### 4. Install Project Dependencies
```bash
pip install -r requirements.txt
```

> **Note for Windows Users**: If `pyaudio` fails during install, run:
> ```bash
> pip install pipwin
> pipwin install pyaudio
> ```

### 5. Install & Prepare Ollama
1. Start the Ollama application or run in a terminal:
   ```bash
   ollama serve
   ```
2. Pull the recommended multilingual Tanglish model:
   ```bash
   ollama pull qwen2.5:3b
   ```
   *(Optional fast fallback model)*:
   ```bash
   ollama pull llama3.2
   ```

## 🎙️ Voice Cloning Setup

Place your reference voice sample (`.wav` format, 6–20 seconds of clear, noise-free speech) into the `voice_samples/` folder:

```text
voice_samples/
├── Induja_Voice.wav    # (Preferred default)
└── my_voice.wav        # (Or your own reference sample)
```

The system automatically resolves the voice sample in the following order:
1. `voice_samples/Induja_Voice.wav`
2. `voice_samples/induja_Voice.wav`
3. `voice_samples/my_voice.wav`
4. Any `.wav` file located in `voice_samples/`

## 🎮 Usage & Running

### Starting Jarvis
Make sure Ollama is running and your Conda environment is active:

```bash
conda activate assistant-voice
python main.py
```

### Conversational Flow
1. **Initialize**: Jarvis will load Faster-Whisper, ChromaDB, XTTS-v2, and Ollama.
2. **Interact**:
   - Press **`ENTER`** to trigger listening mode.
   - Speak into your microphone (default listening window is 5–8 seconds).
   - Watch the LLM stream words to the terminal and synthesize voice sentence-by-sentence.
3. **Exit**: Type `exit`, `quit`, or `bye` at the prompt to shut down gracefully.

## ⚙️ Configuration Reference (`config.py`)

All global parameters can be customized in [`config.py`](file:///d:/DDON/Voice-Assistant/config.py):

| Parameter | Default Value | Description |
|---|---|---|
| `PRIMARY_LLM_MODEL` | `"qwen2.5:3b"` | Preferred Ollama model for Tanglish & conversation |
| `FALLBACK_LLM_MODEL` | `"llama3.2"` | Secondary model if primary is not installed |
| `MAX_HISTORY_TURNS` | `10` | Number of previous dialogue turns preserved in context |
| `LLM_OPTIONS["num_ctx"]` | `2048` | Context token limit (conserves VRAM) |
| `STT_ENGINE` | `"whisper"` | Speech-to-text engine (`"whisper"` or `"google"`) |
| `WHISPER_MODEL_SIZE` | `"base"` | Faster-Whisper model size (`"tiny"`, `"base"`, `"small"`) |
| `WHISPER_DEVICE` | `"cpu"` | Device for STT (`"cpu"` saves GPU memory for XTTS) |
| `WHISPER_COMPUTE_TYPE` | `"int8"` | Quantization type for CPU execution speed |
| `TTS_SPEED` | `1.1` | Speech playback rate multiplier |
| `TTS_TEMPERATURE` | `0.65` | XTTS generation temperature (expressiveness) |
| `RELEVANCE_DISTANCE_THRESHOLD` | `1.2` | Max ChromaDB vector distance for recalling memory |

## 🔧 Troubleshooting

### 1. `torch` is not installed or DLL errors on Windows
If you see `[Environment Error] 'torch' is not installed in the active environment!`, make sure you are in the correct Conda environment:
```powershell
deactivate
conda activate assistant-voice
python main.py
```

### 2. cuDNN Status Mismatch / CUDA Error on Laptop GPUs
`mouth.py` explicitly disables cuDNN via `torch.backends.cudnn.enabled = False` and sets `KMP_DUPLICATE_LIB_OK = "TRUE"`. This prevents crashes on Windows laptop GPUs (such as RTX 3050) while retaining full CUDA acceleration.

### 3. Ollama Connection Issues (`10061` / `ConnectError`)
Ensure the Ollama desktop service is running or execute `ollama serve` in a separate command terminal. `brain.py` will attempt to launch Ollama in the background if offline.

### 4. Microphone Input Not Detected
Check that your operating system's default input device is set to your active microphone. You can test audio recording with `python ear.py`.
